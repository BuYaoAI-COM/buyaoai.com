# 报告指南与归档

想找模型、算预算，还是给 AI 接上工具？这里把已有数据整理成简短报告，通常每篇精选 10–20 项，让你先找到值得继续了解的方向。

报告可以直接在本仓库阅读，保留必要的报价算例、日期和选择依据。完整目录、历史与更多条件，到 [buyaoai.com](https://buyaoai.com/) 继续查。

已发布文章见下方[报告归档](#报告归档)，以下介绍各栏目与阅读方式。

## 价格与成本

同样的调用量，换个模型花多少钱？选一小组同条件报价，列出输入／输出价与可复算的预算。不同币种、缓存和 Batch 分开看，缺失不补零，便宜不等于更适合。

[到模型大全查完整价格条件 →](https://buyaoai.com/models/)

## MCP 与 Agent Skills

从浏览器、搜索、测试和日常工作流出发，每项一句用途。MCP 的工具接入与 Skills 的任务做法分别介绍；兼容、权限、依赖和许可在详情中核对，收录不等于安装测试通过。

[浏览 MCP →](https://buyaoai.com/mcps/) · [浏览 Agent Skills →](https://buyaoai.com/skills/)

## 模型更新与退役

挑出一段时间内值得补看的上新与迁移日程。发布日期、API 上架日与官方关闭日程分别说明，不从采集日期猜首发，也不把公告当作实测停服。

[打开模型发布日志 →](https://buyaoai.com/models/timeline/)

## 工具场景指南

围绕编程、知识库、办公和媒体工作流整理少量候选。每项说明适合什么任务，平台、BYOK 和费用条件到详情核对；未知不推定为免费或已支持。

[去工具目录按自己的需求筛 →](https://buyaoai.com/tools/)

## 公开测评解读

先按任务选榜单，再读分数。保留基准、运行时间、样本与配置的必要提醒，完整成绩留在网站；不同基准不合成总分，第三方结果不写成本站实测。

[查测评与完整成绩 →](https://buyaoai.com/evaluations/)

## 怎样读一篇报告

先看摘要与清单，再核对日期、比较条件和资料缺口。历史文章保留发布时的范围，有实质变化另发新一期；需要勘误时说明修订内容。
