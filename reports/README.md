# 报告指南与归档

AI 更新很快，选型却需要一点耐心。我们希望把分散的型号、报价、工具资料和测评条件整理成一篇篇能查、能比较、能回头看的报告。

你可以先读摘要找到重点，再看表格和比较条件。如果想换个筛选条件、继续查某个型号或工具，就沿着报告里的链接到 [buyaoai.com](https://buyaoai.com/) 看详情。

当前首批数据报告正在整理，尚未发布。以下介绍报告栏目与选题方向；示例标题用于说明内容，不是已发布文章。

## 价格与成本

**同样的调用量，换个模型要花多少钱？**

价格报告会把输入、输出、缓存及 Batch 等计费条件分开列出，并在数据足够时给出固定用量的费用示例。你可以看到金额是怎么算出来的，也能把用量换成自己的情况。

- 重点看：型号与渠道、币种、计费单位、输入／输出单价、适用条件及报价观测日期。
- 比较方式：同一组条件下对照；不同币种、媒体计费和不同处理模式分别列出。
- 阅读提醒：费用示例只计算明确列出的项目；缺失价格保留未知，低价也不等同于能力更强。

选题示例：《AI API 价格对照：同样的调用量，要花多少钱？》

[先到模型目录查看价格与规格 →](https://buyaoai.com/models/)

## MCP 与 Agent Skills

**想让 AI 帮你查库、读文档、操作浏览器，从哪里找资源？**

这类报告从任务出发，把相关 MCP 和 Agent Skills 分开整理。除了功能介绍，也会列出已有资料中的兼容要求、维护信息、许可及官方入口。

- 重点看：能处理什么任务、适用环境、已知接入条件和资料核对日期。
- 组织方式：按场景分组，每个条目给出简短说明和继续了解的入口。
- 阅读提醒：目录收录、仓库热度与实际安装测试分别说明；资料不完整的条目会标注缺口。

选题示例：《让 AI 接上数据库、浏览器和文档：这份 MCP 清单值得收藏》

[浏览 MCP →](https://buyaoai.com/mcps/) · [浏览 Agent Skills →](https://buyaoai.com/skills/)

## 模型更新与退役

**忙了一周，哪些变化值得补看，哪些日程需要提前留意？**

模型动态报告会汇总有明确依据的新型号、价格变化、API 关闭公告和迁移日程，并关联到具体型号与适用范围。

- 重点看：发生了什么、涉及哪些版本、公告或日程日期、有什么资料可继续核对。
- 时间说明：发布日期、报价观测日期和未来关闭日期各自保留，不相互替代。
- 阅读提醒：官方公布的关闭日程与实际连通性分别说明；API 变化也不自动代表权重不可用。

选题示例：《这周 AI 模型变了什么？新型号、价格变化和迁移提醒》

[查看模型发布日志 →](https://buyaoai.com/models/timeline/)

## 工具场景指南

**手里有个具体任务，哪些工具值得先了解？**

工具指南围绕编程、知识库、办公等场景整理候选，尽量把平台、部署方式、模型接入和费用条件放到一起，方便你按自己的要求缩小范围。

- 重点看：用途、支持平台、是否支持自带 API Key（BYOK）、托管或自部署方式，以及已知费用条件。
- 组织方式：说明为什么列入这个场景，再提供可核对的字段与官方入口。
- 阅读提醒：仅在已核对的字段范围内比较；未知的费用、许可或功能不会推定为免费、可商用或已支持。

选题示例：《想用自己的 API Key？先看看这些支持 BYOK 的 AI 工具》

[到工具目录继续筛选 →](https://buyaoai.com/tools/)

## 公开测评解读

**看到一个高分，还需要问哪些问题？**

测评解读会保留原报告的基准版本、指标、样本和运行条件，帮助你理解同一项测试下的差异；有合适数据时，再结合价格讨论选型。

- 重点看：测的是什么、谁发布、何时运行、涉及哪个精确型号，以及哪些结果能放在一起比较。
- 比较方式：优先在相同基准和可比条件下对照，保留分项成绩及其解释。
- 阅读提醒：不同测评不随意合成总分，开发者自报、第三方报告和本站实测分别标识。

选题示例：《挑编程模型，除了榜单分数，还该看哪些条件？》

[查看测评目录与报告 →](https://buyaoai.com/evaluations/)

## 怎样读一篇报告

开头先看它回答什么问题、数据截至哪天，以及几条关键发现。接着看对照表、费用示例或分项结果，最后核对覆盖范围、缺失数据和比较条件。

每篇报告会保留自己的数据时间范围。有实质变化时，我们会发布后续报告并关联前文；历史文章继续保留，便于回头对照。发现错误时会说明修订内容。
