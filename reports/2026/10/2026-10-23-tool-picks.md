## 先按手里的事挑

| 工具（点开看详情） | 适合从什么任务开始 |
| --- | --- |
| [Aider](https://buyaoai.com/tool/?id=aider) | 在终端中与模型协作修改代码，官方配置可用于核对具体模型 ID。 |
| [Cline](https://buyaoai.com/tool/?id=cline) | 在 IDE、终端或桌面中执行编程任务，可按文档配置不同模型渠道。 |
| [Cursor](https://buyaoai.com/tool/?id=cursor) | 按模型和用量池选择编辑器中的 AI 编程能力，先核对订阅与实际用量条件。 |
| [Cherry Studio](https://buyaoai.com/tool/?id=cherry-studio) | 在跨平台桌面客户端中使用多个模型提供方，先核对各渠道与功能条件。 |
| [Open WebUI](https://buyaoai.com/tool/?id=open-webui) | 自托管对话界面可连接 Ollama 与 OpenAI 兼容接口，适合统一管理本地和云模型。 |

| [AnythingLLM](https://buyaoai.com/tool/?id=anythingllm) | 与本地资料对话并配置智能体，适合构建个人或团队文档知识库。 |
| [Dify](https://buyaoai.com/tool/?id=dify) | 用可视化工作流、RAG 与模型管理构建 AI 应用，按部署及提供方文档选择接入。 |
| [OpenHands](https://buyaoai.com/tool/?id=openhands) | 通过 Agent Canvas 组织本地、远端或云端智能体工作流，按官方说明配置执行环境。 |
| [ComfyUI](https://buyaoai.com/tool/?id=comfyui) | 通过节点工作流组织图片、视频与音频生成，按版本和工作流模板核对模型支持。 |
