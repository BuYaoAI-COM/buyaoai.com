# buyaoai.com · 不要爱，只要 AI

模型又上新了，价格又变了，收藏夹里的工具也越来越多。真到要用的时候，我们更想知道：哪个适合手里的事，接入要花多少钱，还有哪些值得一试？

[buyaoai.com](https://buyaoai.com/) 把 AI 模型、API 服务、智能工具、MCP 和 Agent Skills 整理到一起，帮你查资料、看差异、缩小选择范围。这个仓库用来分享基于采集数据整理的报告，也给你留一个方便回来的入口。

## 快速看一遍，也能继续往下查

README 帮你找到主题；报告把某个时间点的数据和发现讲清楚；网站提供目录、筛选、详情和比较，方便你接着核对自己的选择。

每篇报告都会注明数据日期、覆盖范围和比较条件。官方声明、第三方测评与本站实测会分别说明；价格缺失、日期未知和资料不完整的地方，也会留在表里。
